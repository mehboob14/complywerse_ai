EPSS is run by FIRST.org. It uses ML over real-world exploit telemetry to estimate, for each CVE, "how likely is this to be exploited in the next 30 days?" (a number from 0 to 1). This matters because CVSS tells you how bad a vuln is theoretically if exploited — but a CVSS-10 that nobody's actually exploiting is less urgent than a CVSS-7 that's getting hammered. Real example: a researcher's proof-of-concept might have CVSS 9.0, but if there's no public exploit and EPSS says 0.001, you have time. A boring-looking CVSS 6.5 with EPSS 0.85 means attackers are already using it — fix it now.
