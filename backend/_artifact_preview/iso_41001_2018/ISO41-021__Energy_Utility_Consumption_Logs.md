### Column Guidance

| Column | What to enter |
|---|---|
| Record ID | Enter a unique log reference for this record, e.g. EUCL-YYYY-0001. |
| Reporting Period Start | Enter the first day covered by the consumption data in YYYY-MM-DD format. |
| Reporting Period End | Enter the last day covered by the consumption data in YYYY-MM-DD format. |
| Facility/Site Name | Enter the official name of the facility, building, site, campus, or asset consuming the utility. |
| Facility/Site ID | Enter the internal asset, property, or facility reference code used by the organisation. |
| Location/Area Covered | Specify the physical scope covered by the record, e.g. whole building, floor, plant room, data centre, car park lighting, tenant area. |
| Utility Type | Select or enter the utility category: Electricity, Natural Gas, Water, District Heating, District Cooling, Fuel Oil, LPG, Diesel, Steam, Wastewater, Other. |
| Meter/Account ID | Enter the meter number, sub-meter ID, invoice account number, or utility supply point identifier used to trace the data. |
| Supplier/Provider | Enter the name of the utility supplier, landlord, network provider, or internal provider supplying the utility. |
| Data Source | State where the figures came from, e.g. utility invoice, smart meter export, BMS, manual meter reading, landlord statement, fuel delivery note, supplier portal. |
| Opening Meter Reading | Enter the opening reading at the start of the period; use numeric values only, or enter N/A if invoice-based consumption is used without readings. |
| Closing Meter Reading | Enter the closing reading at the end of the period; use numeric values only, or enter N/A if invoice-based consumption is used without readings. |
| Reading Unit | Enter the unit shown on the meter or source document, e.g. kWh, m3, litres, gallons, tonnes, MWh. |
| Consumption Quantity | Enter the total consumption for the period as a numeric value after any meter multiplier or conversion has been applied. |
| Consumption Unit | Enter the final reporting unit for consumption, e.g. kWh, MWh, m3, litres, tonnes, kg. |
| Estimated or Actual Data | Enter Actual, Estimated, or Mixed to indicate data reliability for ISO 41001 performance monitoring. |
| Estimation Method | If data is Estimated or Mixed, describe the method used, e.g. prior period average, degree-day adjustment, supplier estimate, pro-rata invoice; enter N/A if Actual. |
| Cost Amount | Enter the total cost for the reporting period as a numeric value excluding tax unless the organisation’s reporting rule requires otherwise. |
| Currency | Enter the ISO 4217 currency code, e.g. USD, EUR, GBP, AED. |
| Applicable Tariff/Rate | Enter the tariff name or rate applied, including unit rate if available, e.g. Standard electricity tariff 0.18 GBP/kWh; enter N/A if not available. |
| Baseline Consumption | Enter the approved baseline consumption for the same facility, utility, and comparable period as a numeric value in the same Consumption Unit. |
| Baseline Period | Enter the baseline period used for comparison, e.g. 2023-01 to 2023-12 or YYYY-MM-DD to YYYY-MM-DD. |
| Performance Target | Enter the relevant sustainability or FM performance target for this utility, e.g. ≤ 50,000 kWh/month, 5% reduction vs baseline, ≤ 0.20 m3/m2/month. |
| Variance to Target | Enter the absolute variance between actual consumption and the target using the same unit as the target; use positive values for over-target and negative values for under-target, unless otherwise defined internally. |
| Variance to Target % | Enter the percentage variance against target using numeric percentage format, e.g. 4.5%, -3.2%. |
| Normalisation Factor | Enter the factor used to make performance comparable, e.g. floor area m2, occupancy count, production units, heating degree days, cooling degree days; enter N/A if not used. |
| Normalised Consumption | Enter consumption divided or adjusted by the normalisation factor, including the unit in the cell if needed, e.g. 18.4 kWh/m2; enter N/A if not used. |
| Greenhouse Gas Emission Factor | Enter the emission factor applied and its source/year, e.g. 0.207 kgCO2e/kWh DEFRA 2024, or enter N/A where not calculated. |
| Estimated CO2e Emissions | Enter calculated emissions for the period in kgCO2e or tCO2e, clearly using the same unit consistently across the log; enter N/A if not calculated. |
| Renewable/Low-Carbon Share % | Enter the percentage of consumption supplied from renewable or low-carbon sources, e.g. 0%, 35%, 100%; enter N/A if not applicable or not known. |
| Anomaly Identified | Enter Yes or No to indicate whether consumption, cost, emissions, or data quality is outside expected range or requires investigation. |
| Anomaly Description | If Anomaly Identified is Yes, describe the issue, e.g. spike vs baseline, missing data, leak suspected, abnormal night load; enter N/A if No. |
| Corrective/Improvement Action Required | Enter the required action to address poor performance, anomaly, or improvement opportunity; enter N/A if no action is required. |
| Action Owner | Enter the role or named person responsible for completing the action; enter N/A if no action is required. |
| Action Due Date | Enter the action completion due date in YYYY-MM-DD format; enter N/A if no action is required. |
| Action Status | Enter Not Started, In Progress, Complete, Overdue, Deferred, or N/A. |
| Evidence Reference/Link | Enter the document reference, file path, URL, invoice number, meter export filename, dashboard link, or BMS report reference supporting the record. |
| Recorded By | Enter the name or role of the person who entered the record. |
| Date Recorded | Enter the date this log entry was created in YYYY-MM-DD format. |
| Reviewed By | Enter the name or role of the person who reviewed the entry for completeness, accuracy, and performance relevance. |
| Review Date | Enter the review date in YYYY-MM-DD format. |
| Review Outcome | Enter Accepted, Accepted with Action, Rejected, or Pending Review, based on the reviewer’s assessment. |

### Maintenance

Owned by the Facilities/Energy Manager with review by the Sustainability or FM Performance Manager; updated at least monthly and after each billing cycle or meter export. Source data should be drawn from utility invoices, smart meters, BMS/EMS platforms, manual meter readings, supplier portals, fuel delivery records, and approved sustainability performance targets/baselines.
