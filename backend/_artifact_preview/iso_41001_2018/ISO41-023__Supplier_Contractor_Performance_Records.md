### Column Guidance

| Column | What to enter |
|---|---|
| Record ID | Enter a unique identifier for this performance record, e.g. SPR-YYYY-NNN. |
| Reporting Period | Enter the period covered by the performance data in YYYY-MM format for monthly reporting, or YYYY-QN for quarterly reporting. |
| Supplier/Contractor Name | Enter the legal or approved trading name of the supplier or contractor being assessed. |
| Supplier/Contractor ID | Enter the supplier/vendor master reference from the procurement, ERP, or FM system. |
| Contract/PO Reference | Enter the contract number, framework agreement reference, purchase order number, or work order reference that governs the service. |
| FM Service Category | Enter the facility management service being delivered, e.g. Cleaning, Security, Catering, Maintenance, Grounds, Waste, Helpdesk, Specialist Contractor. |
| Site/Asset/Service Area | Enter the site, building, asset group, floor, zone, or service area to which the performance record relates. |
| Contract Owner | Enter the internal role or named person accountable for the contract, e.g. Facilities Manager. |
| Supplier Relationship Owner | Enter the internal role or named person responsible for day-to-day supplier performance management. |
| SLA/KPI Reference | Enter the exact SLA, KPI, service standard, or contract clause reference being measured, e.g. SLA-03, KPI-05, Contract Cl. 7.2. |
| SLA/KPI Description | Describe the service level or key performance indicator being monitored, using the wording from the contract, SLA, or service specification. |
| Target Performance Level | Enter the agreed target or threshold, including value and unit, e.g. ≥95%, ≤4 hours, 100% statutory compliance, zero missed visits. |
| Measurement Method | State how performance is calculated or verified, e.g. CAFM job timestamps, helpdesk report, inspection checklist, audit sample, meter reading, attendance log. |
| Actual Performance | Enter the measured result for the reporting period as a number, percentage, time value, count, or qualitative result aligned to the KPI. |
| Unit of Measure | Enter the unit used for the actual performance result, e.g. %, hours, days, count, score/5, Yes/No, Pass/Fail. |
| Performance Status | Select one allowed value: Green - Met/Exceeded, Amber - At Risk/Minor Shortfall, Red - Not Met, Grey - Not Measured/Not Applicable. |
| Number of Service Requests/Jobs | Enter the total number of relevant jobs, visits, tasks, work orders, calls, or service requests in scope for this KPI during the reporting period. |
| Number Completed Within SLA | Enter the count of in-scope jobs, visits, tasks, or requests completed within the agreed SLA requirement. |
| SLA Breach Count | Enter the number of times the supplier failed to meet the SLA/KPI during the reporting period; enter 0 if none. |
| SLA Breach Details | For each breach, briefly record date, job/reference number, requirement missed, and reason if known; enter N/A if no breach occurred. |
| Nonconformity/Incident Reference | Enter the linked nonconformity, incident, complaint, audit finding, or corrective action reference if applicable; enter N/A if none. |
| User/Customer Feedback Score | Enter the relevant satisfaction or feedback result for the period, including scale, e.g. 4.2/5 or 82%; enter N/A if not measured. |
| HSE/Compliance Issues | Record any health, safety, environmental, statutory, regulatory, permit, induction, insurance, or competence compliance issues; enter None if no issues occurred. |
| Evidence Reference/Link | Enter the document name, report reference, system report ID, folder path, or hyperlink where objective evidence is retained. |
| Corrective Action Required | Select one allowed value: Yes, No. |
| Corrective Action Description | If corrective action is required, describe the action agreed to restore performance or prevent recurrence; enter N/A if not required. |
| Action Owner | Enter the person or role responsible for completing the corrective action; enter N/A if no action is required. |
| Action Due Date | Enter the agreed due date for corrective action in YYYY-MM-DD format; enter N/A if no action is required. |
| Action Status | Select one allowed value: Not Started, In Progress, Completed, Overdue, Cancelled, N/A. |
| Action Closure Date | Enter the date the corrective action was verified as closed in YYYY-MM-DD format; enter N/A if not closed or not applicable. |
| Escalation Required | Select one allowed value: Yes, No. |
| Escalation Details | If escalation is required, record escalation level, recipient, date, and decision or next step; enter N/A if not escalated. |
| Commercial Impact | Record any service credit, penalty, withheld payment, bonus, variation, cost recovery, or no commercial impact; include amount and currency where applicable. |
| Review Outcome | Select one allowed value: Accept Performance, Monitor, Corrective Action Required, Escalated, Supplier Improvement Plan Required, Contract Review Required, Termination Consideration. |
| Reviewed By | Enter the name and role of the person who reviewed and accepted the performance record. |
| Review Date | Enter the date the performance record was reviewed in YYYY-MM-DD format. |
| Next Review Date | Enter the next scheduled supplier performance review date in YYYY-MM-DD format. |
| Record Status | Select one allowed value: Draft, Under Review, Approved, Closed, Superseded. |

### Maintenance

The Contract Owner or Facilities Manager owns this template and ensures it is updated at least monthly, and additionally after supplier review meetings, significant SLA breaches, incidents, or contract changes. Data should be drawn from the CAFM/IWMS or helpdesk system, contract/SLA documents, procurement or ERP supplier records, inspection reports, incident/nonconformity logs, and approved supplier performance review minutes.
