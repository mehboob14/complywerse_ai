### Column Guidance

| Column | What to enter |
|---|---|
| Audit Programme Year | Enter the calendar or financial year covered by this audit programme; format YYYY or YYYY/YYYY. |
| Audit ID | Enter a unique identifier for the planned audit; use a controlled format such as IA-FMS-YYYY-###. |
| Audit Title | Enter a short descriptive title for the audit, e.g. Facilities Maintenance Process Audit. |
| FMS Process / Area to be Audited | Enter the specific facilities management system process, function, service, contract, or operational area to be audited. |
| Facility / Site / Location | Enter the physical site, building, region, campus, or location covered by the audit; use 'Organisation-wide' if applicable. |
| ISO 41001:2018 Clause(s) | Enter the applicable ISO 41001:2018 clause references to be audited, e.g. 4.1, 6.1, 8.1, 9.1, 9.2; separate multiple clauses with commas. |
| Organisation FMS Requirement(s) / Procedure Ref(s) | Enter the internal FMS policy, procedure, contract, SLA, process map, work instruction, or documented requirement reference used as audit criteria. |
| Audit Criteria | Enter the requirements against which evidence will be assessed, including ISO 41001 clauses, internal procedures, legal/contractual requirements, SLAs, and customer/user requirements where applicable. |
| Audit Scope | Define the boundaries of the audit, including included processes, activities, services, locations, departments, time period, and any exclusions. |
| Audit Objective | State what the audit is intended to determine, such as conformity to ISO 41001 and internal FMS requirements, effective implementation, or effectiveness of specific controls. |
| Reason for Inclusion / Priority Basis | Enter why this audit is scheduled, considering process importance, FMS risks/opportunities, service criticality, legal/contractual importance, recent changes, incidents, performance issues, or previous audit results. |
| Risk / Importance Rating | Select one value: High, Medium, Low; base the rating on process criticality, risk to facilities services, compliance exposure, customer/user impact, or prior performance. |
| Changes Since Last Audit Considered | Record relevant changes considered when planning the audit, such as organisational change, new suppliers, changed service scope, new systems, incidents, revised procedures, or write 'None identified'. |
| Previous Audit Result Considered | Summarise the relevant previous audit outcome considered for programme planning, e.g. No findings, Minor NCs, Major NC, repeat issue, overdue actions, or Not previously audited. |
| Planned Audit Frequency | Enter the planned recurrence for this audit, e.g. Annual, Semi-annual, Quarterly, Biennial, One-off, or Risk-based. |
| Planned Audit Start Date | Enter the planned audit start date in YYYY-MM-DD format. |
| Planned Audit End Date | Enter the planned audit end date in YYYY-MM-DD format. |
| Audit Method | Select one or more methods: On-site, Remote, Hybrid, Document review, Interview, Observation, Sampling, System walkthrough. |
| Lead Auditor | Enter the name or role of the assigned lead auditor responsible for planning, conducting, and reporting the audit. |
| Audit Team Members | Enter names or roles of other assigned auditors or technical experts; enter 'None' if not applicable. |
| Independence / Impartiality Confirmation | Confirm that assigned auditor(s) are independent of the activity being audited; select Yes, No, or Mitigation required, and add brief mitigation if independence risk exists. |
| Auditee Process Owner | Enter the name or role of the manager responsible for the process or area being audited. |
| Relevant Management to Receive Report | Enter the management role(s), committee, or leadership forum that will receive the audit results. |
| Planned Report Issue Date | Enter the planned date for issuing the internal audit report in YYYY-MM-DD format. |
| Audit Status | Select one value: Planned, Scheduled, In progress, Completed, Deferred, Cancelled. |
| Audit Report / Record Reference | Enter the controlled reference or hyperlink to the audit report or retained documented information once completed; leave blank until available. |
| Linked Corrective Action Reference | Enter the corrective action, nonconformity, or improvement action reference(s) raised from the audit; leave blank until available or enter 'None' after completion if no actions are raised. |
| Programme Approval | Select one value: Draft, Submitted, Approved, Revision required. |
| Programme Approved By | Enter the name and role of the person approving the internal FMS audit programme. |
| Programme Approval Date | Enter the approval date in YYYY-MM-DD format; leave blank until approved. |
| Notes / Constraints | Enter any planning constraints, dependencies, blackout periods, access limitations, sampling considerations, or coordination requirements. |

### Maintenance

The FMS Compliance Manager or Internal Audit Programme Owner owns this template and updates it at least annually, and whenever significant FMS changes, risks, incidents, or previous audit results require programme revision. Source inputs should be drawn from the FMS process register, risk and opportunity register, previous internal audit reports, corrective action log, management review outputs, CAFM/service management system, legal/compliance register, and approved FMS procedures.
