### Column Guidance

| Column | What to enter |
|---|---|
| Record ID | Enter a unique identifier for this inspection/test record, e.g. ITR-YYYY-0001. |
| Site/Facility | Enter the name or code of the facility where the inspection/test was performed. |
| Building/Area/Asset Location | Enter the specific building, floor, room, zone, plant room, or external area inspected; use the organisation’s location naming convention. |
| Asset/System/Service Inspected or Tested | Enter the asset, system, infrastructure element, or FM service inspected/tested, e.g. fire alarm system, lift, HVAC unit, water hygiene, emergency lighting. |
| Asset ID/Tag | Enter the asset register ID, tag number, serial number, or system reference; enter N/A only where no asset ID exists. |
| Inspection/Test Type | Enter the type of inspection or test performed, e.g. visual inspection, functional test, statutory examination, compliance inspection, performance test, sampling, calibration check. |
| Statutory/Routine Category | Select one: Statutory, Regulatory, Contractual, Manufacturer Requirement, Internal Routine, Risk-Based, Other. |
| Legal/Regulatory/Other Requirement Reference | Enter the applicable legal, regulatory, contractual, manufacturer, or internal requirement reference driving the inspection/test; enter N/A for purely discretionary checks. |
| ISO 41001 Clause/Process Reference | Enter the relevant ISO 41001 or FM process reference, normally ISO 41001:2018 Cl. 9.1 and any internal procedure/control ID. |
| Inspection/Test Standard or Method | Enter the procedure, checklist, standard, manufacturer instruction, or test method used, including document number and version where applicable. |
| Planned Frequency | Enter the required frequency, e.g. Daily, Weekly, Monthly, Quarterly, 6-Monthly, Annual, 5-Yearly, Event-Based, Risk-Based. |
| Planned Due Date | Enter the scheduled due date for the inspection/test in YYYY-MM-DD format. |
| Actual Inspection/Test Date | Enter the date the inspection/test was completed in YYYY-MM-DD format. |
| Inspection/Test Provider | Enter Internal or the name of the external contractor/competent body that performed the inspection/test. |
| Inspector/Tester Name | Enter the full name of the person who performed the inspection/test. |
| Competence/Certification Reference | Enter the licence, qualification, authorisation, appointment, training record, or competent person certificate reference; enter N/A if not applicable. |
| Instrument/Equipment Used | Enter any test instrument, meter, analyser, gauge, or equipment used, including equipment ID where applicable; enter N/A if no instrument was used. |
| Instrument Calibration Status | Enter Calibrated, Not Required, Out of Calibration, or Unknown; where calibrated, include calibration due date in YYYY-MM-DD format. |
| Acceptance Criteria/Pass Requirements | Enter the measurable or observable criteria used to determine pass/fail, including thresholds, limits, tolerances, or checklist requirements. |
| Results/Readings Observed | Enter the actual observed result, reading, measurement, or inspection finding, including units where applicable, e.g. °C, bar, lux, ppm, %, minutes. |
| Result Status | Select one: Pass, Fail, Conditional Pass, Not Tested, Not Applicable. |
| Nonconformity/Defect Description | If the result is Fail or Conditional Pass, describe the defect, nonconformity, unsafe condition, missed requirement, or limitation; enter N/A if none. |
| Risk/Severity Rating | Select the assessed risk or severity using the organisation’s scale, e.g. Low, Medium, High, Critical, or RAG: Green, Amber, Red. |
| Immediate Action Taken | Enter any action taken at the time of inspection/test to make safe, isolate, repair, escalate, or control the issue; enter N/A if none. |
| Corrective/Follow-up Action Required | Enter the action required to correct the defect/nonconformity or improve performance; enter N/A if no follow-up is required. |
| Action Owner | Enter the named role or person responsible for completing the corrective/follow-up action; enter N/A if no action is required. |
| Target Completion Date | Enter the planned completion date for the corrective/follow-up action in YYYY-MM-DD format; enter N/A if no action is required. |
| Actual Completion Date | Enter the actual date the corrective/follow-up action was completed in YYYY-MM-DD format; leave blank until completed or enter N/A if no action is required. |
| Verification/Retest Date | Enter the date the completed action was verified or retested in YYYY-MM-DD format; enter N/A if verification/retest is not required. |
| Verification/Retest Result | Select one: Pass, Fail, Accepted by Risk Assessment, Not Required, Pending. |
| Certificate/Report Reference | Enter the certificate number, inspection report number, work order number, or service report reference generated from the inspection/test. |
| Evidence/File Link | Enter the controlled repository link or file path to the certificate, report, checklist, photos, readings, or signed record. |
| Next Inspection/Test Due Date | Enter the next required due date in YYYY-MM-DD format, calculated from the applicable frequency, statutory interval, risk assessment, or provider recommendation. |
| Record Retention Period | Enter the required retention period for this record, e.g. 3 years, 5 years, life of asset, statutory period, or as defined in the document retention schedule. |
| Reviewed By | Enter the full name or role of the person who reviewed the record for completeness, compliance, and required actions. |
| Review Date | Enter the date the record was reviewed in YYYY-MM-DD format. |
| Comments | Enter any additional relevant notes, exclusions, access limitations, operational constraints, or cross-references; enter N/A if none. |

### Maintenance

Owned by the Facilities Compliance Manager or FM Compliance Lead and updated after each statutory, regulatory, contractual, risk-based, or routine inspection/test, with periodic review at least monthly for overdue actions and at least annually for template adequacy. Source data should be drawn from the CAFM/CMMS, asset register, statutory compliance register, contractor inspection reports, certificates, work orders, and controlled document repository.
