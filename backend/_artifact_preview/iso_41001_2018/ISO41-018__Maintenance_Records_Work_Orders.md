### Column Guidance

| Column | What to enter |
|---|---|
| Work Order ID | Enter the unique work order or maintenance record number from the CMMS or work order system; format should match the source system identifier. |
| Record Type | Select one value: Planned Maintenance, Reactive Maintenance, Corrective Maintenance, Preventive Maintenance, Predictive Maintenance, Inspection, Statutory Maintenance, Emergency Repair. |
| Maintenance Category | Enter the maintenance discipline or service type, e.g. HVAC, Electrical, Plumbing, Fire Safety, Lifts, Fabric, Security, Cleaning Equipment, Grounds, Utilities. |
| Request/Trigger Source | Enter what initiated the work, e.g. maintenance plan, inspection finding, occupant request, alarm, breakdown, statutory inspection, audit finding, condition monitoring. |
| Request Date | Enter the date the request or trigger was logged in format YYYY-MM-DD. |
| Requested By | Enter the name, role, department, or system that raised the request. |
| Facility/Site | Enter the facility, site, campus, or property name where the work is required. |
| Building/Floor/Area | Enter the specific building, floor, room, zone, plantroom, external area, or location identifier. |
| Asset ID | Enter the asset register ID/tag number for the maintained asset; use N/A only where the work is not asset-specific. |
| Asset Description | Enter a short description of the asset or maintainable item, including make/model where useful. |
| Asset Criticality | Select one value based on the asset register: Critical, High, Medium, Low, N/A. |
| Issue/Task Description | Describe the defect, task, inspection, maintenance activity, or service requirement clearly enough for the assignee to perform the work. |
| ISO 41001 Clause Reference | Enter the relevant management system reference; for this template use ISO 41001:2018 Cl. 8.1 unless the organisation maps additional internal controls. |
| Service Level/Response Requirement | Enter the applicable SLA, response time, completion target, or maintenance frequency, e.g. 4-hour response, complete within 5 working days, monthly PM. |
| Priority | Select one value: Emergency, Urgent, High, Medium, Low, Routine. |
| Operational Risk/Safety Impact | State the operational, health and safety, environmental, business continuity, security, or occupant impact; enter None if not applicable. |
| Statutory/Regulatory Requirement | State any legal, code, permit, inspection, warranty, or compliance obligation linked to the work; enter N/A if none. |
| Planned Due Date | Enter the required completion date in format YYYY-MM-DD, based on the maintenance plan, SLA, risk priority, or statutory requirement. |
| Scheduled Start Date/Time | Enter the planned start date and time in format YYYY-MM-DD HH:MM using local time; leave blank until scheduled. |
| Assigned Team/Technician | Enter the internal maintenance team, technician, engineer, or responsible role assigned to complete the work. |
| External Contractor | Enter the approved contractor company and contact name if outsourced; enter N/A if completed internally. |
| Permit/Access Required | Select one value: Yes, No; use Yes where permits, isolations, confined space, hot works, roof access, security access, or occupant coordination are required. |
| Permit/Access Reference | Enter the permit number, access approval, isolation certificate, method statement approval, or visitor/access reference; enter N/A if not required. |
| Work Method/Procedure Reference | Enter the SOP, maintenance instruction, risk assessment, method statement, manufacturer manual, checklist, or job plan reference used. |
| Materials/Parts Required | List key parts, consumables, tools, or materials required, including part numbers and quantities where known; enter None if not required. |
| Work Status | Select one value: New, Triaged, Scheduled, In Progress, On Hold, Awaiting Parts, Awaiting Contractor, Completed Pending Verification, Closed, Cancelled. |
| Actual Start Date/Time | Enter the actual start date and time in format YYYY-MM-DD HH:MM using local time; leave blank until work starts. |
| Actual Completion Date/Time | Enter the actual physical completion date and time in format YYYY-MM-DD HH:MM using local time; leave blank until work is completed. |
| Downtime Duration | Enter asset or service downtime duration in hours to one decimal place, e.g. 2.5; enter 0 if no downtime occurred. |
| Work Performed/Completion Notes | Record what was actually done, inspections/tests completed, parts replaced, readings taken, and any deviations from the planned method. |
| Root Cause | For reactive/corrective work, enter the known or suspected cause of failure; enter N/A for routine planned maintenance or where not determined. |
| Follow-up Action Required | Select one value: Yes, No; use Yes where further maintenance, investigation, replacement, monitoring, risk control, or capital work is needed. |
| Follow-up Action Owner | Enter the person or role responsible for the follow-up action; enter N/A if no follow-up is required. |
| Follow-up Due Date | Enter the due date for follow-up action in format YYYY-MM-DD; enter N/A if no follow-up is required. |
| Completion Verified By | Enter the name and role of the person who verified the work was completed and acceptable, e.g. supervisor, facilities manager, requester, authorised engineer. |
| Verification Date | Enter the date completion was verified in format YYYY-MM-DD. |
| Quality/Acceptance Result | Select one value: Accepted, Accepted with Follow-up, Rework Required, Failed Test, Not Verified. |
| Evidence/Attachment Reference | Enter links or references to supporting evidence such as photos, inspection sheets, test certificates, service reports, permits, invoices, or calibration records. |
| Cost | Enter the total cost of labour, parts, and contractor charges in the organisation's reporting currency, e.g. 1250.00 GBP; enter 0.00 if not tracked. |
| Customer/Occupant Impact | Describe any impact to users, occupants, visitors, service delivery, access, comfort, safety, or operations; enter None if no impact. |
| Customer/Occupant Communication | Record communication issued or required, including notice reference, date/time, audience, and channel; enter N/A if not required. |
| Closed Date | Enter the date the work order was administratively closed in format YYYY-MM-DD after verification and evidence upload. |
| Closed By | Enter the name and role of the person closing the record in the CMMS or work order system. |
| Retention/Archive Reference | Enter the document repository path, archive ID, or retention classification for the completed record and evidence. |

### Maintenance

Owned by the Facilities/Maintenance Manager or CMMS Administrator, with each work order updated in real time from request through closure and reviewed at least monthly for overdue, recurring, statutory, and high-risk items. Source data should be drawn from the CMMS/work order system, asset register, planned preventive maintenance schedule, service desk, contractor reports, permits, and completed inspection/test evidence.
