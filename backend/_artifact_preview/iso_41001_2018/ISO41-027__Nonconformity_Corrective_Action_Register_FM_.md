### Column Guidance

| Column | What to enter |
|---|---|
| NC ID | Enter a unique identifier for the nonconformity, using a consistent format such as NC-FM-YYYY-###. |
| Date Identified | Enter the date the nonconformity was first identified in YYYY-MM-DD format. |
| Identified By | Enter the name and role of the person who identified or reported the nonconformity. |
| Source of Nonconformity | Select or enter the source, such as Internal Audit, External Audit, Management Review, Client Complaint, Service Failure, KPI Monitoring, Supplier Issue, Incident, Inspection, Employee Report, or Other. |
| ISO 41001 Clause / FMS Requirement | Enter the applicable ISO 41001:2018 clause, contractual requirement, internal procedure, SLA, policy, or FM requirement that was not met. |
| FM Process / Service Area | Enter the affected facilities management process or service area, such as maintenance, cleaning, security, catering, utilities, space management, helpdesk, contractor management, asset management, or H&S interface. |
| Location / Site | Enter the site, building, floor, asset location, client location, or operational area affected by the nonconformity. |
| Nonconformity Description | Describe clearly what failed to conform, including what happened, where, when, and the requirement not met; do not include root cause unless already verified. |
| Objective Evidence | Enter the evidence supporting the nonconformity, such as audit finding, work order number, inspection record, photo reference, complaint ID, KPI report, log entry, or document reference. |
| Immediate Correction / Containment Taken | Record immediate action taken to control, correct, contain, or mitigate the nonconformity and its consequences, including date if applicable. |
| Consequences / Impact | Describe the actual or potential impact on FM service delivery, users, client obligations, safety, compliance, assets, business continuity, environment, cost, or reputation. |
| Severity | Enter the assessed severity using agreed values such as Low, Medium, High, or Critical, based on organisational criteria. |
| Responsible Owner | Enter the manager accountable for ensuring the nonconformity is investigated and resolved. |
| Root Cause Analysis Method | Enter the method used to determine cause, such as 5 Whys, Fishbone, Fault Tree, Pareto, Incident Investigation, Process Review, or Not Required with justification. |
| Root Cause | Enter the verified underlying cause or causes of the nonconformity; avoid restating the symptom. |
| Similar or Potential Nonconformities Assessed | Record whether similar nonconformities exist or could occur elsewhere, including areas checked; use Yes, No, or Not Applicable with brief explanation. |
| Corrective Action Required | Enter Yes or No; use Yes where action is needed to eliminate the root cause and prevent recurrence or occurrence elsewhere. |
| Corrective Action Plan | Describe the planned corrective action(s) to eliminate the root cause, including enough detail to verify implementation. |
| Action Owner | Enter the person or role responsible for completing the corrective action. |
| Target Completion Date | Enter the planned completion date for the corrective action in YYYY-MM-DD format. |
| Actual Completion Date | Enter the date the corrective action was fully implemented in YYYY-MM-DD format; leave blank until complete. |
| Implementation Status | Enter the current status using Not Started, In Progress, Implemented Pending Effectiveness Review, Closed, Overdue, or Cancelled. |
| Effectiveness Review Method | Describe how effectiveness will be verified, such as repeat audit, KPI trend review, inspection, sample check, customer feedback, work order review, or observation. |
| Effectiveness Review Date | Enter the date the effectiveness review was or will be performed in YYYY-MM-DD format. |
| Effectiveness Review Result | Enter the outcome of the effectiveness review using Effective, Not Effective, Partially Effective, or Pending, with a brief rationale. |
| Further Action Required | Enter any additional corrective action required if the original action was not effective, or enter None. |
| Risks / Opportunities Updated | Enter Yes, No, or Not Applicable and reference the risk/opportunity register entry updated where relevant. |
| FMS Documentation / Process Changes Required | Enter any required updates to FMS documents, procedures, work instructions, training, contracts, SLAs, process maps, or controls; enter None if no change is required. |
| Evidence Reference / Link | Enter document IDs, system links, folder paths, work order references, audit report numbers, photos, approvals, or other records proving actions and results. |
| Closure Approval By | Enter the name and role of the authorised person approving closure, independent of the action owner where practicable. |
| Closure Date | Enter the date the nonconformity and corrective action were formally closed in YYYY-MM-DD format. |
| Record Status | Enter Open, Closed, Reopened, or Archived. |

### Maintenance

The FMS Manager or designated Quality/FM Compliance Manager owns this register and updates it whenever a nonconformity is identified, with formal review at least monthly and before management review. Source data is drawn from audits, inspections, FM helpdesk/CMMS, complaints, KPI reports, incident records, supplier performance records, and management review outputs.
