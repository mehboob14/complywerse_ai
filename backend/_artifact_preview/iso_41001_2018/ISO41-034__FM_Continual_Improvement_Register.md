### Column Guidance

| Column | What to enter |
|---|---|
| Improvement ID | Enter a unique identifier for the improvement initiative, using a controlled format such as CI-YYYY-###. |
| Date Raised | Enter the date the improvement opportunity was formally logged, in YYYY-MM-DD format. |
| Raised By | Enter the name and role or function of the person who identified or submitted the improvement opportunity. |
| Improvement Source | Select the origin of the improvement from allowed values: Internal Audit, External Audit, Management Review, KPI Trend, Customer Feedback, Complaint, Risk Assessment, Incident, Nonconformity, Supplier Review, Staff Suggestion, Benchmarking, Regulatory Change, Technology / Innovation, Other. |
| Source Reference | Enter the reference number, report name, meeting minute ID, audit finding ID, KPI dashboard link, ticket number, or other traceable source reference. |
| ISO 41001 Clause / FM Process | Enter the relevant ISO 41001 clause where applicable and/or the FM process affected, for example Cl. 8.1 Operations, Cl. 9.1 Performance Evaluation, Maintenance, Cleaning, Space Management, Helpdesk, Security, Energy Management. |
| Facility / Site / Service Area | Enter the specific facility, site, building, region, department, asset group, or FM service area to which the improvement applies. |
| Interested Party / Customer Affected | Enter the customer, client, occupier group, internal department, regulator, supplier, user group, or other interested party affected by the improvement. |
| Current Issue or Opportunity Statement | Describe the current condition, gap, inefficiency, trend, risk, or opportunity in clear factual terms; avoid describing the solution only. |
| Improvement Category | Select the primary intent from allowed values: Improve FM Service, Improve FMS Effectiveness, Enhance Customer Satisfaction, Reduce Undesired Effect, Prevent Undesired Effect, Correct Undesired Effect, Improve Efficiency, Improve Compliance, Improve Sustainability, Other. |
| Intended Improvement Objective | State what the initiative is intended to achieve, written as a measurable improvement objective where possible. |
| Alignment to FM Policy / FM Objectives | Identify the relevant FM policy commitment, FM objective, performance target, customer requirement, or strategic business aim supported by the improvement. |
| Baseline Performance / Current State | Record the starting performance level or current state before action, including metric name, value, unit, and measurement period where applicable. |
| Target Outcome / Success Measure | Define the expected result and acceptance criteria, including KPI, target value, unit, threshold, or qualitative success condition. |
| Risk or Opportunity Rating | Enter the assessed significance using the organisation's risk method, for example Low, Medium, High, Critical, or a numeric score such as Likelihood x Impact. |
| Priority | Select the implementation priority from allowed values: Low, Medium, High, Urgent. |
| Proposed Improvement Action | Describe the planned action or initiative to implement the improvement, including key deliverables or change activities. |
| Action Owner | Enter the named person and role accountable for coordinating and delivering the improvement action. |
| Approver / Sponsor | Enter the manager, process owner, contract lead, FM director, or governance body approving resources and priority for the initiative. |
| Resources or Budget Required | Record required resources such as budget, labour, contractor support, tools, technology, training, or capital expenditure; include amount and currency where known. |
| Planned Start Date | Enter the planned commencement date for the improvement action, in YYYY-MM-DD format. |
| Target Completion Date | Enter the planned completion date for the improvement action, in YYYY-MM-DD format. |
| Status | Select the current lifecycle status from allowed values: Proposed, Approved, Not Started, In Progress, On Hold, Completed, Effectiveness Review Pending, Closed, Cancelled. |
| Progress / Update Notes | Enter dated progress notes, decisions, blockers, escalations, or changes to scope; each update should include date, author, and summary. |
| Related Corrective Action ID | Enter any linked corrective action, nonconformity, incident, risk treatment, audit finding, or CAPA reference; enter N/A if not applicable. |
| Evidence / Record Location | Enter the controlled document repository path, system link, ticket URL, project folder, report reference, or other evidence location proving implementation. |
| Actual Completion Date | Enter the date the improvement action was completed, in YYYY-MM-DD format; leave blank until completed. |
| Effectiveness Review Required | Select Yes or No to indicate whether post-implementation effectiveness must be verified. |
| Effectiveness Review Date | Enter the planned or actual date for checking whether the improvement achieved its intended outcome, in YYYY-MM-DD format. |
| Effectiveness Review Result | Record the result of the effectiveness check using allowed values: Effective, Partially Effective, Not Effective, Too Early to Confirm, Not Required; include brief rationale if needed. |
| Benefit Realised | Record the actual benefit achieved, including measured KPI change, cost saving, risk reduction, service improvement, customer satisfaction result, compliance improvement, or qualitative benefit. |
| Lessons Learned / Standardisation Action | Record any lessons learned and whether changes were embedded into procedures, training, specifications, contracts, checklists, asset plans, or monitoring arrangements. |
| Closure Approval | Enter the name, role, and approval decision of the person authorised to close the initiative after completion and effectiveness review. |
| Closure Date | Enter the date the improvement initiative was formally closed, in YYYY-MM-DD format. |

### Maintenance

The FM Management System Manager owns this template, with updates made at least monthly and reviewed during management review for trends, overdue actions, and effectiveness of improvements. The register draws from the GRC/CAPA system, FM helpdesk or CAFM system, audit reports, KPI dashboards, customer feedback records, risk registers, and management review outputs.
