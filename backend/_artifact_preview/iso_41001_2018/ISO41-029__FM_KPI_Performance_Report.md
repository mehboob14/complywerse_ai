### Column Guidance

| Column | What to enter |
|---|---|
| Reporting Period | Enter the period covered by the KPI result in format YYYY-MM or YYYY-Q#; for annual reporting use YYYY. |
| Report Issue Date | Enter the date this report version is issued in format YYYY-MM-DD. |
| FM Objective Reference | Enter the unique reference of the related facilities management objective, e.g. FM-OBJ-001; must align to the organisation's FM objectives register. |
| KPI ID | Enter a unique KPI identifier, e.g. FM-KPI-001; use one row per KPI per reporting period. |
| KPI Name | Enter the short name of the performance indicator being monitored, e.g. Planned Maintenance Completion Rate. |
| FM Service / Process Area | Enter the FM service, process, asset group, contract, site, or function being measured, e.g. Maintenance, Cleaning, Security, Utilities, Helpdesk, Space Management. |
| ISO 41001 Clause Reference | Enter the applicable ISO 41001:2018 reference; for this report use Cl. 9.1 unless the KPI also supports another clause. |
| Interested Party / Requirement Monitored | Enter the stakeholder need, statutory requirement, SLA, contract obligation, policy commitment, or user requirement being monitored. |
| KPI Definition | Define exactly what is being measured, including numerator and denominator where applicable, so the calculation is repeatable. |
| Measurement Method | Describe how the result is calculated or assessed, including formula, sampling method, inspection method, or system report used. |
| Unit of Measure | Enter the measurement unit, e.g. %, number, hours, days, kWh, m2, cost, score, incidents/month. |
| Measurement Frequency | Enter how often the KPI is measured; allowed values: Daily, Weekly, Monthly, Quarterly, Annually, Per Event, Other. |
| Data Source / System | Enter the authoritative source of data, e.g. CAFM, CMMS, BMS, IWMS, finance system, energy platform, contractor report, audit checklist. |
| Data Owner | Enter the role or team accountable for the accuracy and completeness of the source data, e.g. CAFM Administrator, Energy Manager, Contractor Manager. |
| KPI Owner | Enter the role accountable for KPI performance and evaluation, e.g. Facilities Manager, Head of FM, Maintenance Manager. |
| Target / Acceptance Criteria | Enter the required target, limit, SLA, threshold, or acceptance criterion, including unit and direction of performance, e.g. >=95%, <=4 hours, zero statutory overdue tasks. |
| Threshold - Green | Enter the result range that represents acceptable performance, including unit and comparator, e.g. >=95%. |
| Threshold - Amber | Enter the result range that represents warning or marginal performance, including unit and comparator, e.g. 90% to <95%. |
| Threshold - Red | Enter the result range that represents unacceptable performance requiring action, including unit and comparator, e.g. <90%. |
| Actual Result | Enter the measured result for the reporting period using the unit stated in Unit of Measure. |
| Variance from Target | Enter the difference between actual result and target, including unit or percentage points; use + or - to show direction. |
| RAG Status | Enter the performance status based on the defined thresholds; allowed values: Green, Amber, Red, Not Rated. |
| Trend vs Previous Period | Enter the direction of performance compared with the previous period; allowed values: Improved, Deteriorated, No Change, New KPI, Not Available. |
| Previous Period Result | Enter the prior reporting period's actual result using the same unit of measure, or N/A if not available. |
| Analysis / Evaluation Summary | Enter the management evaluation of the result, including cause of variance, patterns, risks, constraints, and whether the KPI remains suitable. |
| Performance Impact | Enter the impact of the result on FM objectives, service delivery, compliance, users, assets, costs, safety, environment, or business continuity. |
| Nonconformity Raised | Enter Yes or No; select Yes where the result indicates failure to meet a requirement requiring nonconformity control. |
| Corrective / Improvement Action Reference | Enter the linked action, corrective action, risk treatment, or improvement reference, e.g. CA-2025-014; enter N/A if no action is required. |
| Action Owner | Enter the role or named accountable person responsible for the linked action; enter N/A if no action is required. |
| Action Due Date | Enter the due date for the linked action in format YYYY-MM-DD; enter N/A if no action is required. |
| Evidence / Record Location | Enter the file path, system report name, dashboard link, audit record, or document reference proving the KPI result and analysis. |
| Prepared By | Enter the name and role of the person compiling the KPI report. |
| Reviewed By | Enter the name and role of the person reviewing the KPI report for accuracy, completeness, and suitability. |
| Approval Status | Enter the report approval state; allowed values: Draft, Under Review, Approved, Rejected, Superseded. |
| Approved By | Enter the name and role of the approving manager; leave blank until approved. |
| Approval Date | Enter the approval date in format YYYY-MM-DD; leave blank until approved. |

### Maintenance

The Facilities Management Performance Manager or Head of FM owns this template and updates it at the defined KPI reporting cadence, typically monthly with quarterly management review consolidation. Data should be drawn from approved source systems such as CAFM/CMMS/IWMS, BMS or energy platforms, helpdesk logs, contractor SLA reports, finance systems, audit records, and statutory compliance registers.
