### Column Guidance

| Column | What to enter |
|---|---|
| Register ID | Enter a unique identifier for the entry using a consistent format, e.g. FMR-YYYY-###. |
| Entry Type | Select one allowed value: Risk, Opportunity, Risk and Opportunity. |
| Date Raised | Enter the date the entry was first recorded in YYYY-MM-DD format. |
| Raised By | Enter the name and role/team of the person raising the entry. |
| FM Domain | Select the main FM area affected: Hard FM, Soft FM, Lifecycle/Asset Management, HSE, Energy/Sustainability, Security, Space/Workplace, Contract/Supplier, Business Continuity, Other. |
| Facility / Asset / Service Scope | Enter the specific site, building, zone, asset class, service contract, or FM service scope affected. |
| Process / Activity | Enter the FM process or activity where the risk/opportunity arises, e.g. planned maintenance, cleaning, catering, statutory inspection, lifecycle planning, helpdesk, contractor management. |
| Issue / Context Source | State the source that identified the issue, e.g. context review, interested-party need, compliance obligation, asset condition survey, incident, audit finding, customer feedback, supplier review, strategic planning. |
| Interested Party / Requirement Affected | Identify the stakeholder or requirement affected, e.g. occupants, client, landlord, regulator, service provider, insurer, community, legal/statutory requirement, SLA/KPI. |
| Risk or Opportunity Statement | Write a clear statement of the uncertain event or condition and its effect on intended FM outcomes; use format: If/when [event/condition], then [impact/benefit] to [FM objective/service outcome]. |
| Cause / Driver | Enter the underlying cause, trigger, vulnerability, trend, or enabling factor creating the risk or opportunity. |
| Potential Consequence / Benefit | Describe the credible negative consequence for risks or positive benefit for opportunities, including effects on compliance, safety, service continuity, cost, asset performance, user experience, sustainability, or lifecycle value. |
| ISO 41001 Clause / FMS Objective Link | Enter the relevant ISO 41001 clause, FM objective, policy commitment, compliance obligation, or KPI/SLA reference that this entry could affect. |
| Existing Controls / Current Arrangements | Describe current measures already in place, such as procedures, inspections, PPM, competency controls, monitoring, contracts, contingency plans, permits, audits, or technology systems. |
| Likelihood Rating | Enter a numeric rating using the organisation's approved scale, typically 1-5 where 1 = Rare and 5 = Almost Certain; define consistently in the workbook legend. |
| Impact Rating | Enter a numeric rating using the organisation's approved scale, typically 1-5 where 1 = Insignificant and 5 = Severe/Major; consider safety, compliance, service, financial, reputation, asset, and environmental impact. |
| Inherent Score | Enter the calculated pre-treatment score, usually Likelihood Rating x Impact Rating; numeric value only. |
| Inherent RAG | Enter the inherent priority band using allowed values: Red, Amber, Green, based on the organisation's approved risk matrix thresholds. |
| Treatment / Response Strategy | Select the intended response: Avoid, Reduce/Mitigate, Transfer/Share, Accept, Exploit, Enhance, Monitor, Contingency Plan, Other. |
| Planned Actions | Describe specific actions to address the risk or opportunity and how they will be integrated into FM processes, plans, contracts, resources, or controls. |
| Action Owner | Enter the accountable role/person responsible for completing the planned actions, not a department only. |
| Target Completion Date | Enter the agreed completion date for planned actions in YYYY-MM-DD format. |
| Resources Required | Enter required budget, labour, contractor support, system changes, materials, training, or management approval needed to implement the action. |
| Residual Likelihood Rating | Enter the expected or confirmed likelihood rating after treatment using the same scale as Likelihood Rating. |
| Residual Impact Rating | Enter the expected or confirmed impact rating after treatment using the same scale as Impact Rating. |
| Residual Score | Enter the calculated post-treatment score, usually Residual Likelihood Rating x Residual Impact Rating; numeric value only. |
| Residual RAG | Enter the residual priority band using allowed values: Red, Amber, Green, based on the approved risk matrix thresholds. |
| Evaluation Method | State how effectiveness of the action/control will be evaluated, e.g. KPI trend, audit, inspection result, incident reduction, statutory compliance evidence, customer satisfaction, cost saving, energy data, lifecycle analysis. |
| Effectiveness Criteria | Enter measurable success criteria that demonstrate the action has addressed the risk/opportunity, including target value, threshold, or pass/fail condition where possible. |
| Review Frequency | Select how often the entry must be reviewed: Monthly, Quarterly, Six-Monthly, Annually, Event-Driven, Project Milestone, Other. |
| Current Status | Select one allowed value: New, Assessed, Action Planned, In Progress, Overdue, Monitoring, Escalated, Closed, Deferred. |
| Last Review Date | Enter the most recent review date in YYYY-MM-DD format; leave blank only for newly raised entries not yet reviewed. |
| Next Review Date | Enter the next planned review date in YYYY-MM-DD format, based on risk level, status, and review frequency. |
| Evidence / Record Reference | Enter document IDs, system links, work order numbers, inspection reports, audit records, meeting minutes, photos, dashboards, or other evidence supporting assessment and action status. |
| Related Incident / Audit / Change Reference | Enter any linked incident, nonconformity, audit finding, change request, project, asset survey, or management review reference; enter N/A if none. |
| Escalation Required | Select Yes or No; select Yes where residual exposure, resource need, compliance risk, or decision authority exceeds local FM authority. |
| Approval Authority | Enter the role or governance body required to approve the assessment, treatment plan, acceptance of residual risk, or opportunity investment, e.g. FM Director, Client Representative, Risk Committee. |
| Closure Date | Enter the date closed in YYYY-MM-DD format; leave blank until the entry is formally closed. |
| Closure Rationale / Lessons Learned | Record why the entry was closed, evidence that effectiveness criteria were met, residual risk acceptance, benefits realised, and any lessons to feed into FM planning or management review. |

### Maintenance

The FM Risk & Opportunity Register is owned by the Facilities Management System Manager or FM Risk Owner, with accountable review by FM leadership. It should be updated when new risks/opportunities, incidents, audits, changes, projects, asset surveys, supplier reviews, or management reviews occur, and formally reviewed at least quarterly using data from the CAFM/IWMS, helpdesk, asset register, compliance tracker, audit system, incident system, supplier performance reports, and management review outputs.
