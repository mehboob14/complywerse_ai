### Column Guidance

| Column | What to enter |
|---|---|
| Record ID | Enter a unique identifier for this competence/training record, e.g. CTR-0001; do not reuse IDs. |
| Employee/Worker ID | Enter the unique HR, contractor, or supplier personnel identifier for the individual; use 'N/A' only where no identifier exists. |
| Name | Enter the individual's full name exactly as recorded in the HR, contractor, or supplier record. |
| Employment Type | Select one value: Employee, Contractor, Agency Worker, Supplier Personnel, Volunteer, Other. |
| Department/Function | Enter the department, team, or function responsible for the person, e.g. Facilities Management, Maintenance, Security, Cleaning, HSE. |
| FM Role/Position | Enter the job title or FM role being assessed, e.g. Facilities Manager, Maintenance Technician, Cleaning Supervisor. |
| Work Location/Site | Enter the site, building, region, or service location where the person performs FM duties. |
| FM Process/Service Area | Enter the FM service or process the competence relates to, e.g. Planned Maintenance, Helpdesk, Asset Management, Cleaning, Security, Space Management, Energy Management. |
| Competence Requirement ID | Enter the unique ID for the competence requirement from the organisation's competence framework, job description, legal register, procedure, or training matrix, e.g. COMP-FM-001. |
| Required Competence/Skill | Describe the specific knowledge, skill, training, qualification, licence, or experience required to perform the FM role or task competently. |
| Competence Category | Select one value: Education, Training, Experience, Qualification, Licence/Certification, Technical Skill, Legal/Regulatory, HSE/Safety, Behavioural/Leadership, System/Process Knowledge. |
| Required Proficiency Level | Enter the required level using the organisation's defined scale, e.g. 1-Awareness, 2-Working Knowledge, 3-Competent to Work Unsupervised, 4-Supervisor/Approver, 5-Expert/Trainer. |
| Requirement Source | Enter the source that establishes the competence requirement, e.g. Job Description, FM Procedure, Legal Requirement, Contract Requirement, Risk Assessment, Manufacturer Requirement, ISO 41001 FMS Requirement, Client Requirement. |
| Mandatory for Role | Select Yes or No to indicate whether the competence is mandatory before the person may perform the role or task. |
| Current Proficiency Level | Enter the person's current assessed level using the same scale as Required Proficiency Level. |
| Competence Evidence Type | Select the main evidence type: Training Record, Certificate, Licence, Qualification, CV/Experience Record, Observation, Interview, Test/Assessment, Work Output Review, Supervisor Attestation, Other. |
| Evidence Reference/Link | Enter the document number, LMS record ID, certificate number, file path, or system link where evidence is stored; do not attach sensitive personal data unless authorised. |
| Competence Assessment Method | Enter how competence was determined, e.g. document review, practical observation, written test, interview, supervisor assessment, probation review, refresher assessment. |
| Assessor Name/Role | Enter the name and role of the competent person, manager, trainer, or assessor who assessed the individual. |
| Assessment Date | Enter the date competence was assessed in YYYY-MM-DD format. |
| Competence Status | Select one value: Competent, Competent with Supervision, Not Yet Competent, Training Required, Expired, Not Applicable. |
| Competence Gap Description | Where Current Proficiency Level is below Required Proficiency Level or evidence is missing/expired, describe the specific gap; enter 'None' if no gap exists. |
| Training/Development Need | Enter the required training, coaching, supervised work, qualification, refresher, or other action needed to close the competence gap; enter 'None' if not required. |
| Training Course/Activity Title | Enter the title of the delivered or planned training/development activity; enter 'N/A' if no training activity applies. |
| Training Provider | Enter the internal trainer, external provider, awarding body, or platform name that delivered or will deliver the training; enter 'N/A' if not applicable. |
| Training Delivery Method | Select one value: Classroom, E-learning, Toolbox Talk, On-the-job Training, Coaching/Mentoring, Practical Assessment, External Course, Briefing, Self-study, Other, N/A. |
| Training Start Date | Enter the start date of the training/development activity in YYYY-MM-DD format; enter 'N/A' if not applicable. |
| Training Completion Date | Enter the completion date in YYYY-MM-DD format; leave blank only if training is planned or in progress. |
| Training Hours | Enter the duration in hours as a number to one decimal place, e.g. 2.5; enter 0 if not applicable. |
| Attendance/Completion Status | Select one value: Planned, In Progress, Completed, Did Not Attend, Cancelled, Failed, Not Applicable. |
| Certificate/Qualification Reference | Enter certificate number, licence number, qualification ID, or LMS completion reference; enter 'N/A' where no certificate or qualification is issued. |
| Certificate/Competence Expiry Date | Enter expiry or refresher due date in YYYY-MM-DD format; enter 'No Expiry' where the evidence does not expire. |
| Effectiveness Evaluation Method | Enter how the organisation verified that training or action was effective, e.g. post-training test, workplace observation, KPI review, supervisor sign-off, audit result, incident reduction, no evaluation required. |
| Effectiveness Evaluation Result | Select one value: Effective, Partially Effective, Not Effective, Pending, Not Required, and add a brief result statement if needed. |
| Effectiveness Evaluation Date | Enter the date effectiveness was evaluated in YYYY-MM-DD format; leave blank only where evaluation is pending or not required. |
| Next Action Required | Enter the follow-up action required, e.g. refresher training, reassessment, supervised practice, obtain certificate, update role matrix, none. |
| Next Review/Due Date | Enter the next planned review, reassessment, refresher, or expiry follow-up date in YYYY-MM-DD format. |
| Manager Approval | Enter approval status and approver name/date, e.g. Approved - Jane Smith - 2026-03-15; use Pending if not yet approved. |
| HR/FM Competence Record Verified By | Enter the name and role of the person who checked the record for completeness and evidence availability. |
| Record Last Updated Date | Enter the date this row was last updated in YYYY-MM-DD format. |
| Notes | Enter any brief relevant clarification, restriction, exception, or audit note; leave blank if none. |

### Maintenance

Owned by the FM Manager with support from HR/Learning & Development and the FM Compliance Coordinator. Update whenever a person joins, changes role, completes training, is reassessed, or evidence expires, and formally review at least quarterly using the HRIS, LMS, contractor onboarding records, competence framework, job descriptions, legal register, FM procedures, and certificate/evidence repository.
