### Column Guidance

| Column | What to enter |
|---|---|
| Record ID | Enter a unique identifier for this training/attendance record, e.g. CTR-YYYY-0001. |
| Training Title | Enter the official name of the training course, briefing, awareness session, induction, or competence activity delivered. |
| Training Type | Enter the category of training using allowed values: Information Security Awareness, Role-Based Security Training, Secure Development, Incident Response, Privacy/Data Protection, Physical Security, Supplier Security, Induction, Refresher, Other. |
| ISO/IEC 27001:2022 Reference | Enter the relevant clause or control reference, typically Cl. 7.2 and/or A.6.3; include any other applicable internal ISMS control reference if relevant. |
| Competence Requirement / Learning Objective | State the specific competence, awareness outcome, or skill the attendee is expected to gain, linked to their role or information security responsibilities. |
| Audience / Role Required | Enter the target audience or role group required to complete the training, e.g. All Employees, Developers, Service Desk, Privileged Users, ISMS Internal Auditors, Senior Management. |
| Mandatory Training | Enter Yes or No to indicate whether the training is mandatory for the attendee’s role. |
| Training Provider | Enter the internal team, individual, external supplier, or learning platform that provided the training. |
| Delivery Method | Enter one allowed value: Classroom, Virtual Live, E-Learning, Toolbox Talk, Workshop, On-the-Job Training, Simulation/Exercise, Other. |
| Training Date | Enter the date the training was delivered or assigned in YYYY-MM-DD format. |
| Training Duration Hours | Enter the duration of the training in hours as a number, e.g. 1, 1.5, 2. |
| Attendee Name | Enter the full name of the person who attended or was assigned the training. |
| Attendee Unique ID | Enter the employee ID, contractor ID, learner ID, or other unique workforce identifier. |
| Job Title / Role | Enter the attendee’s current job title or functional role at the time of training. |
| Department / Team | Enter the attendee’s department, business unit, or team. |
| Employment Type | Enter one allowed value: Employee, Contractor, Temporary Worker, Supplier, Intern, Other. |
| Manager / Approver | Enter the attendee’s line manager or responsible approver for competence and training requirements. |
| Attendance Status | Enter one allowed value: Attended, Completed Online, Assigned Not Started, In Progress, Absent, Cancelled, Exempted. |
| Completion Date | Enter the date the attendee completed the training in YYYY-MM-DD format; leave blank if not completed. |
| Assessment Required | Enter Yes or No to indicate whether a test, quiz, observation, exercise evaluation, or other assessment was required. |
| Assessment Method | Enter the method used to assess competence, e.g. Quiz, Practical Exercise, Manager Observation, Simulation, Interview, Attendance Only, Not Applicable. |
| Score / Result | Enter the score or outcome achieved, including units where applicable, e.g. 85%, 18/20, Satisfactory, Completed; use Not Applicable if no assessment was required. |
| Pass Mark | Enter the required pass threshold or acceptance criterion, e.g. 80%, 16/20, Satisfactory; use Not Applicable if no assessment was required. |
| Pass / Fail Status | Enter one allowed value: Pass, Fail, Not Applicable, Pending. |
| Competence Achieved | Enter Yes, No, or Pending to indicate whether the required competence has been demonstrated based on completion and assessment results. |
| Retraining Required | Enter Yes or No to indicate whether further training is required due to failure, absence, role change, expired competence, or management decision. |
| Retraining Due Date | Enter the required retraining deadline in YYYY-MM-DD format; leave blank if retraining is not required. |
| Certificate / Evidence Reference | Enter the certificate number, LMS completion ID, attendance sheet reference, assessment record ID, or other evidence identifier. |
| Record Location / Link | Enter the file path, SharePoint/Teams link, LMS URL, HRIS reference, or document repository location where supporting evidence is stored. |
| Trainer / Assessor Name | Enter the name of the trainer, facilitator, assessor, or system that delivered or assessed the training. |
| Trainer / Assessor Competence Evidence | Enter a brief reference confirming the trainer/assessor is competent, e.g. qualification, certification, role experience, approved trainer list reference, or Not Applicable for automated LMS content. |
| Notes / Exceptions | Enter any relevant exception, exemption reason, late completion note, accessibility adjustment, or management decision; leave blank if none. |
| Record Created Date | Enter the date this record was first created in YYYY-MM-DD format. |
| Record Last Updated Date | Enter the date this record was last updated in YYYY-MM-DD format. |
| Record Owner | Enter the role accountable for maintaining this record, e.g. HR Learning Manager, ISMS Manager, Security Awareness Lead. |

### Maintenance

Owned by the HR Learning Manager with oversight from the ISMS Manager or Security Awareness Lead. Update after each training event or LMS completion import, review at least monthly, and draw source data from the LMS, HRIS, attendance sheets, assessment results, certificates, and the ISMS competence/training matrix.
