## Purpose

The purpose of this document is to record and maintain a log of periodic reviews of user access rights in compliance with ISO/IEC 27001:2022 control A.5.18. This ensures that access rights are appropriate and align with the principle of least privilege, thereby reducing the risk of unauthorized access to information assets.

## Scope

This record/log applies to all user accounts with access to [Organization Name]'s information systems, including but not limited to employees, contractors, and third-party users. The access review process is conducted [quarterly/annually] and encompasses all systems classified as critical or containing sensitive information.

## Captured Fields

| Field                | Description                                                                 |
|----------------------|-----------------------------------------------------------------------------|
| Review Date          | The date on which the access review was conducted.                          |
| Reviewer Name        | The name of the individual conducting the access review.                    |
| System/Application   | The specific system or application being reviewed.                          |
| User ID              | The unique identifier of the user whose access rights are being reviewed.   |
| Access Level         | The current access level assigned to the user.                              |
| Justification        | The reason for the current access level, as provided by the system owner.   |
| Changes Required     | Details of any changes required to the user's access rights.                |
| Change Implementation Date | The date on which any required changes to access rights were implemented. |
| Comments             | Additional notes or comments regarding the review process.                  |
