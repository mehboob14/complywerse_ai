Description

Apache Log4j2 versions 2.0-beta9 through 2.14.1 do not protect against attacker-controlled JNDI lookups. An attacker who can control log messages or log message parameters can execute arbitrary code loaded from LDAP servers when message lookup substitution is enabled. Affects log4j-core 2.14.1, detected on this asset via CPE match.

CWE: CWE-917 — Improper Neutralization in Expression Language Statement
Component: log4j-core@2.14.1
