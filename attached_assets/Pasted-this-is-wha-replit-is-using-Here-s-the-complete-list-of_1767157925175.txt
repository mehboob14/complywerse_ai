To present "8 parents → their child controls → each control's evidence" you join/aggregate pci_dss_requirements with required_evidence. Below are compact, copyable queries and a one-line Python approach.- Quick flat join (show each control with its evidence rows) SELECT p.requirement_number, p.id AS control_id, p.subsection_number, p.subsection_text, e.required_evidence_id, e.evidence_type, e.description, e.frequency, e.source FROM public.pci_dss_requirements p LEFT JOIN public.required_evidence e ON p.id = e.control_id ORDER BY p.requirement_number, p.id;
- Controls grouped with evidence per control (one row per control, evidence as JSON array) SELECT p.requirement_number, p.id AS control_id, p.subsection_number, p.subsection_text, COALESCE(( SELECT json_agg(json_build_object( 'id', re.required_evidence_id, 'type', re.evidence_type, 'description', re.description, 'frequency', re.frequency, 'source', re.source )) FROM public.required_evidence re WHERE re.control_id = p.id ), '[]'::json) AS evidence FROM public.pci_dss_requirements p ORDER BY p.requirement_number, p.id;
- Aggregate by major requirement (one row per requirement, list of controls each with evidence) SELECT p.requirement_number, json_agg(json_build_object( 'control_id', p.id, 'subsection_number', p.subsection_number, 'subsection_text', p.subsection_text, 'evidence', COALESCE(( SELECT json_agg(json_build_object( 'id', re.required_evidence_id, 'type', re.evidence_type, 'description', re.description, 'frequency', re.frequency, 'source', re.source )) FROM public.required_evidence re WHERE re.control_id = p.id ), '[]'::json) ) ORDER BY p.id) AS controls FROM public.pci_dss_requirements p GROUP BY p.requirement_number ORDER BY p.requirement_number;
- Count evidence items per major requirement SELECT p.requirement_number, COUNT(re.*) AS evidence_count FROM public.pci_dss_requirements p LEFT JOIN public.required_evidence re ON p.id = re.control_id GROUP BY p.requirement_number ORDER BY p.requirement_number;
